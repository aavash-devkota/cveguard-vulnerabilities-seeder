# CVEGuard Vulnerabilities Seeder
[![Go](https://img.shields.io/badge/Go-seeder-blue)](https://go.dev)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Go seeder that fetches and populates vulnerability (CVE) data for
[CVEGuard](https://github.com/aavash-devkota/cveguard-server).

## Run

```bash
go run main.go
```

## Requires

- Go 1.21+
- Database credentials via environment/config
